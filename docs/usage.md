# 使用指南

[返回首页](../README.md)

## 下载与校验

从 [GitHub Releases](https://github.com/blockshy/DupeFileCleaner/releases/latest) 下载 Windows x64 ZIP 及对应的 `.sha256` 文件。保持二者文件名不变，在下载目录打开 PowerShell：

```powershell
# 将版本号替换为下载文件的实际版本，比较本机计算值与随包提供的校验值。
$archive = 'DupeFileCleaner-v1.1.1-windows-x64.zip'
$expected = (Get-Content -LiteralPath "$archive.sha256" -Raw).Split(' ')[0].Trim()
$actual = (Get-FileHash -LiteralPath $archive -Algorithm SHA256).Hash
if ($actual -ne $expected) { throw '校验失败，请重新下载并核对来源。' }
'SHA-256 校验通过'
```

完整解压后启动 `dupe_file_cleaner.exe`。程序依赖同目录 DLL 和 `data` 文件夹，请保留整个目录。便携发行包不写入系统安装目录；用户偏好与执行记录保存在 Windows 的本地应用数据目录。

## 设置扫描范围

点击“添加文件夹…”使用原生目录选择器。Ctrl / Shift 可以选择多个目录，也可以在输入框粘贴完整路径后点击添加。使用列表右侧的移除按钮缩小范围。

所有根目录统一参与判重，因此不同目录中的相同内容也会归为一组。相同路径只保留一次，已被父目录包含的子目录不会重复扫描。改变目录列表或扫描选项会清除当前结果，需要重新扫描。

| 选项 | 默认值 | 作用 |
|---|---|---|
| 包含空文件 | 关闭 | 控制普通文件结果是否包含零字节文件 |
| 包含硬链接 | 关闭 | 允许普通文件检测考虑硬链接；同一文件身份的别名仍保守跳过 |
| 检测完整重复文件夹 | 开启 | 比较完整目录树；其清单始终包含空文件和空子目录 |

符号链接、连接点及其他重解析点均跳过，通过这些链接访问的扫描根不接受。部分云存储占位文件可能作为重解析点呈现；这些项目会被跳过，不会强制下载或跟随链接。

## 重复文件

扫描先按长度分组，再读取首尾各最多 128 KiB 计算快速摘要，最终对候选读取完整内容并计算 SHA-256。完整读取以分块方式进行，不要求将大文件整体载入内存。相同名称不是判重条件，长度相同但内容不同也不会成为同一重复组。

每组默认保留最后修改时间最早的一份；时间相同时按规范化绝对路径排序。界面显示时间采用本机时区，“最早”不是创建时间。可通过“改为保留”调整保留对象，保留项不会被勾选为清理目标。

普通文件的候选默认勾选。开始清理前应核对完整路径，并取消不希望处理的项目。

## 完整重复文件夹

完整文件夹分组要求以下信息全部一致：

- 文件的相对路径及文件长度。
- 每个文件的完整 SHA-256，包括零字节文件。
- 子目录的相对路径与结构，包括空子目录。

路径按 Windows 不区分大小写的规则比较。如果两份文件夹包含同一批内容，但文件名或层级不同，不会作为可整目录清理的副本。纯空文件夹不列为候选；任一项目读取失败、包含链接或硬链接、或在扫描期间变化，也会使相应完整目录树退出候选。

程序优先列出最大的完整副本，避免同时选择相互包含的父目录和子目录。默认按规范化路径排序保留一份，其他文件夹需要主动勾选。可打开“查看完整清单”，核对所有文件与子目录。

每棵树最多支持 **8192 个文件及子目录**，根目录本身不计入。超限父树会被跳过并提示，符合上限的重复子树仍可列出。磁盘根目录和共享根目录禁止作为整目录清理目标。

## 清理与连续处理

文件和文件夹使用独立结果页，一次任务只处理当前页选中的对象。确认框显示扫描范围、项目数量和逻辑大小；文件夹任务还显示包含的文件数。

| 方式 | 行为 |
|---|---|
| 移入回收站 | 默认方式，仅支持本地固定磁盘；失败不会自动降级为永久删除 |
| 永久删除 | 必须精确输入 `DELETE`，不能通过回收站恢复 |

每次执行都会重新验证保留对象和候选的身份、真实路径、元数据及完整内容。整目录操作还会重新枚举两边的清单，发现新增、缺失、改名、类型变化或链接项目时拒绝该项。永久目录清理只删除已复核的文件，再自底向上移除空目录，不递归删除清单之外的内容。

Windows Shell 的回收操作无法提供与按文件句柄删除相同的原子性保证。请先停止可能更改目标目录的同步、下载或编辑任务，再执行清理。

清理成功后，仅移除已处理或受影响的结果：

- 同组尚有至少两份副本时，保留该组；其他独立组、人工保留选择和未处理勾选继续可用。
- 整目录删除会同步移除其内部文件的结果。如果文件保留项也被删除，从剩余副本中重新保护一份，并取消其清理勾选。
- 单文件清理只使包含它的完整目录成员失效；其他完整副本可以继续使用。
- 组内不足两份时，移除该组。已完整删除的扫描根也从剩余计划移除。

明确失败或跳过的项目保留供检查后重试。部分完成或结果不确定时，仅移除关联分组并停止批次；相关内容需要重新扫描，其他独立结果仍可使用。

## 取消与恢复

扫描与清理期间可以点击取消。取消是协作式的，程序会停止尚未执行的工作，已完成的操作不会自动回滚。任务忙碌时窗口关闭会被拦截，应先取消并等待停止。

回收站恢复由 Windows 资源管理器完成。程序不会自动重放中断的计划，也不会自动恢复删除结果。恢复文件或手动更改目录后，应重新扫描，以建立新的内容与身份快照。

## 计划导入与导出

“导出计划”只保存当前结果页中仍被勾选的候选及其保留对象。应保存到结果涉及的完整重复文件夹之外，避免写入计划文件改变该目录的内容。

当前计划格式为版本 3，支持多个扫描根和完整文件夹清单。版本 1、2 的旧版计划也可导入，但所有版本均会重新读取和验证内容；导入不意味着信任计划中的路径与摘要。任一组成员不匹配，该组会被跳过。导入计划大小上限为 64 MiB。

计划包含完整路径、文件身份、修改时间和摘要。分享计划前应检查其中的信息，公开反馈请优先使用可复现的合成样本。

## 设置、日志与本地数据

| 位置 | 内容 |
|---|---|
| `%LOCALAPPDATA%\DupeFileCleaner\settings.json` | 浅色、深色或跟随系统的主题偏好 |
| `%LOCALAPPDATA%\DupeFileCleaner\history\plan-*.json` | 每次清理前固定的执行计划 |
| `%LOCALAPPDATA%\DupeFileCleaner\history\cleanup-*.jsonl` | 按行保存的操作日志 |

日志包含 `begin`、`intent`、`result` 和 `finish` 记录，每条写入后刷新到磁盘。`intent` 表示准备操作，`result` 表示已收到执行结果。如果存在没有对应 `result` 的 `intent`，该项结果未知，应先检查目标和回收站，再决定是否重扫或重试。

应用没有云端扫描、用户账号或遥测上传功能。计划和日志可能含文件名、完整路径、摘要及错误详情；提交 Issue 前请脱敏。程序不会自动清空系统回收站或删除历史日志。退出程序后可按需自行归档或移除应用历史记录，这不会恢复已经删除的文件。

## 常见问题

**为什么显示的可清理容量不等于实际释放空间？**

界面统计的是逻辑文件大小。回收站中仍保留的内容、硬链接、压缩文件和稀疏文件都可能导致实际磁盘空间不同。

**为什么某项被跳过？**

在“详情与日志”中查看具体原因。常见情况包括路径已变化、文件被占用、内容变化、权限不足、链接项目、目录清单不完整或超出整目录规模上限。修正原因后重新扫描或重试，不要直接修改计划里的身份与摘要来绕过检查。

**文件夹看起来相同，为什么没有列为完整重复文件夹？**

检查相对文件名、子目录结构、空文件和空子目录是否一致，并查看跳过及错误记录。包含相同内容但不同文件名的两个目录，仍可通过“重复文件”页逐项处理。

**清理一项之后，是否必须重新扫描所有目录？**

不需要。未受影响的结果可以继续处理；只有被移除的关联结果、外部发生变化的内容或手动恢复后的内容需要重新扫描。

**更新程序会丢失设置吗？**

先退出旧版，再将新版完整解压到独立目录运行。主题与历史记录存放在本地应用数据目录，不在程序 ZIP 内。旧计划导入后仍需重新复核。
